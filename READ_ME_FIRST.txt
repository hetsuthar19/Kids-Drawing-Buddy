KIDS DRAWING BUDDY
==================

FINAL VERSION

Main changes:
1. App name changed to:
       Kids Drawing Buddy

2. Account wording changed to:
       User Login
       User Account

3. Age selection changed to:
       4, 5, 6, 7, 8 years

4. Drawing illustrations improved:
       - cleaner black outlines
       - fewer unnecessary details
       - large closed coloring areas
       - simple kid-friendly shapes
       - less messy gallery previews

5. Drawing tools:
       - Fill
       - Manual Paint Brush
       - Eraser
       - Small / Medium / Large brush
       - Color palette
       - Undo
       - Reset

6. Auto-save:
       - fill colors save automatically
       - brush strokes save automatically
       - erasing saves automatically
       - child can leave and continue later
       - gallery shows saved colored progress
       - drawings show Start / In progress / Completed


HOW TO RUN ON WINDOWS
---------------------

1. Extract the ZIP file.

2. Open the extracted:
       kids_drawing_buddy_final
   folder.

3. Double-click:
       START_HERE.bat

4. The first run automatically creates the Python environment
   and installs Flask + Werkzeug.

5. Keep the black terminal window OPEN.

6. The app opens at:
       http://127.0.0.1:5000


OPEN THE CODE IN VS CODE
------------------------

Open:
       Kids-Drawing-Buddy.code-workspace

If imports are red:

1. Press Ctrl + Shift + P
2. Select:
       Python: Select Interpreter
3. Choose:
       .venv\Scripts\python.exe
4. Reload VS Code.
